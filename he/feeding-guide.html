טבלת דישון

צמח Universal Flowering Multicote

דשנים

Flower Universal

Универсальное жидкое удобрение NPK 5-5-7. Подходит для большинства растений в период активного роста.

Flower Flowering

Удобрение для цветущих растений с повышенным содержанием фосфора и калия. Стимулирует цветение.

Ecogan Multicote

Гранулированное удобрение пролонгированного действия. НЕ использовать на фитильном поливе!

Flower Orchids 0-17-7

Специальное удобрение для орхидей в фазе цветения. 0% азота, 17% фосфора — только для цветения!

תוספים

🍄 DYNOMYCO Spark

Микориза + бактерии Bacillus + гуминовая кислота. 1 ч.л. на 4 л, каждые 1-2 недели. Для укоренения и пересадки.

⬆️ BioBizz Bio·Up

Органический pH Up на гуминовых кислотах. 0.1 мл/л = +0.1 pH. Не вредит микоризе!

⬇️ Green Farmer pH-

Минеральный pH Down. По каплям до нужного значения. Использовать с осторожностью.

כללי השקיה (תמיד)

  • Cal-Mag: Используйте только с RO (осмос) водой для предотвращения дефицита минералов.
  • pH: Регулируйте в конце, после всех добавок. Bio·Up для повышения (органика), pH- для понижения.
  • DYNOMYCO: После применения НЕ вносить фосфорные удобрения — высокий P подавляет микоризу.
  • Хищники: ТОЛЬКО чистый RO (TDS < 10), никаких добавок и удобрений.
  • Multicote: Запрещён для растений на фитильном поливе — вымывается и вызывает ожог корней.
