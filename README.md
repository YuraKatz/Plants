# База данных домашних растений

Структурированная база данных для ухода за домашними растениями в формате YAML.

## 📁 Структура проекта

```
Plants/
├── README.md               # Документация (этот файл)
├── plants.yaml             # База данных растений (20 видов)
├── soil-mixes.yaml         # Рецепты грунтовых смесей (11 смесей)
├── components.yaml         # Компоненты грунта и субстраты
├── fertilizers.yaml        # Удобрения и подкормки
├── water-requirements.yaml # Требования к воде для RO-системы

├── lamps.md               # Практика установки фитоламп

├── QUICK-START.md         # Быстрое начало работы

```

## 🌿 Описание файлов

### `plants.yaml`
Содержит информацию о 20 видах домашних растений:
- Гузмания, Драцена (2 вида), Кротон, Эпипремнум
- Филодендрон, Хамедорея, Калатея (2 вида)
- Монстера (2 вида), Спатифиллум, Бегония макулата
- Аглаонема, Орхидея фаленопсис, Хлорофитум
- Алоказия, Антуриум, Дионея (хищное)
- Папоротник (Нефролепис), Сансевиерия

**Структура данных для каждого растения:**
```yaml
plants:
  plant_id:
    name: Название растения
    latin_name: Латинское название
    type: Тип растения
    lighting: Требования к освещению
    watering:
      method: Метод полива
      frequency: Частота
      notes: Дополнительные заметки
    humidity:
      level: Уровень влажности
      spraying: Опрыскивание
      preferred_method: Предпочтительный метод
    wick_watering:
      recommended: true/false
      notes: Заметки по фитильному поливу
    soil:
      mix_number: Номер смеси
      mix_name: Название смеси
      alternative_mix: Альтернативная смесь (опционально)
    risks: [Список рисков]
    care_notes: [Особенности ухода]
```

### `water-requirements.yaml`
Требования к воде для системы обратного осмоса (RO):
- **Индивидуальные требования** для каждого растения (PPM, pH)
- **3 группы растений** по типу воды (A, B, C)
- **Практические рекомендации** по приготовлению воды
- **Диагностика проблем** с водой

**Структура:**
```yaml
water_requirements:
  individual_requirements:
    plant_id:
      plant_name: Название
      ppm_range: 60-90
      ph_range: 5.8-6.2
      group: A/B/C
      sensitivity: very_high/medium/low
      notes: Комментарий
  water_groups:
    group_a:
      name: Очень мягкая вода
      ppm_target: 80
      ppm_range: 60-90
      ph_range: 5.8-6.3
      plants: [Список растений]
  general_rules: [Правила]
  practical_setup: [Схема бутылок]
  troubleshooting: [Решение проблем]
```

**Ключевые концепции:**
- **Основа:** RO (осмос) + CalMag обязательно!
- **3 группы воды:** A (~80 ppm), B (~120 ppm), C (~150 ppm)
- **PPM важнее pH** для чувствительных растений
- **Стабильность > точность**

### `troubleshooting.yaml`
Диагностическая система для решения проблем с растениями:
- **8 частых симптомов** с детальной диагностикой
- **20+ причин** проблем с указанием вероятности
- **12 подробных решений** с пошаговыми протоколами лечения
- **Decision tree** для интерактивной диагностики
- **Quick reference** для экстренных ситуаций

**Структура:**
```yaml
troubleshooting:
  symptoms:
    symptom_id:
      name: Название симптома
      severity: low/medium/high/critical
      possible_causes:
        - cause_id: причина
          probability: вероятность
          indicators: [признаки]
  causes:
    cause_id:
      severity: уровень опасности
      affected_plants: [особо уязвимые]
  solutions:
    solution_id:
      urgency: срочность
      steps: [пошаговая инструкция]
      prevention: [профилактика]
  decision_tree: [интерактивная диагностика]
  quick_reference:
    emergency_situations: [критичные случаи]
    most_common_mistakes: [частые ошибки]
```

**Покрываемые проблемы:**
- Желтеющие листья → перелив, дефицит азота, хлороз
- Коричневые кончики → низкая влажность, соли, жёсткая вода
- Вялые листья → недолив, гниение корней
- Белый налёт → накопление солей, жёсткая вода
- Гниение корней → CRITICAL (немедленные действия)
- Замедленный рост, опадение листьев, пятна на листьях

### `lighting.md`
Практическое руководство по освещению для комнатных растений:
- **Основа:** измеримые значения в Lux
- **Универсальная шкала:** от 500 до 25000 lux
- **Целевые значения** для каждого растения (в plants.yaml)
- **Практические советы:** окно vs лампа, измерение, компенсация
- **Фотопериод:** сколько часов светить

**Ключевой принцип:**
> Лучше стабильные 6000–8000 lux 10–12 часов, чем 15000 lux 3 часа

**Связь:**
- `plants.yaml` → содержит `lux_min`, `lux_optimal`, `lux_max` для каждого растения
- `lighting.md` → объясняет как применять эти цифры на практике

**Таблица уровней:**
- Очень низкий: 500–1000 (выживание)
- Низкий: 1000–3000 (теневыносливые)
- Средний: 3000–8000 (норма)
- Яркий: 8000–15000 (активный рост)
- Очень яркий: 15000–25000 (цветение/риск ожога)

### `lamps.md`
Практическое руководство по установке и настройке фитоламп:
- **Типы ламп:** LED, люминесцентные, что выбрать и чего избегать
- **Закон обратных квадратов:** почему расстояние критично
- **Практические расстояния:** таблицы для разных мощностей
- **Зона покрытия:** сколько растений под одной лампой
- **Схемы подвеса:** одно растение, полка, стеллаж
- **Мощность и расчёты:** сколько ватт на растение
- **Таймер и фотопериод:** автоматизация освещения
- **Комбинация окно + лампа:** как использовать вместе
- **Типовые ошибки:** 5+ частых ошибок с решениями
- **Практический чек-лист:** перед тем как считать "готово"
- **Примеры расчётов:** 3 реальных сценария с решениями

**Ключевой алгоритм:**
```
1. Купить лампу (full spectrum LED)
2. Повесить на 20-40 см
3. Измерить Lux люксметром
4. Сравнить с lux_optimal из plants.yaml
5. Скорректировать высоту
6. Настроить таймер на 10-12 часов
```

**Связь:**
- `plants.yaml` → целевой lux_optimal для настройки
- `lighting.md` → теория (что такое Lux)
- `lamps.md` → практика (как добиться нужного Lux)

## 📋 Ключевые концепции

### Типы полива
- **Ручной** - традиционный полив сверху с просушкой грунта
- **Фитильный** - автополив через фитиль, требует более лёгкого грунта

### Категории растений по типу
- Бромелиевые
- Ложные пальмы
- Пестролистные
- Лианы
- Ароидные
- Пальмы
- Марантовые
- Декоративно-цветущие
- Эпифитные орхидеи
- Папоротники
- Суккуленты
- Хищные

### Уровни влажности
- **Средняя** - обычная комнатная влажность
- **Средняя-высокая** - желательно повышение влажности
- **Высокая** - обязателен увлажнитель или поддоны с водой

### Требования к воде (RO-система)
- **Group A (60-90 ppm)** - очень мягкая вода для чувствительных растений
  - Калатея, Спатифиллум, Орхидея, Гузмания
- **Group B (90-140 ppm)** - средняя минерализация для большинства
  - Монстера, Филодендрон, Эпипремнум, Аглаонема, Бегония, Хамедорея
- **Group C (120-170 ppm)** - более насыщенная вода
  - Драцена, Кротон
- **Правило:** RO + CalMag обязательно! Чистый осмос использовать нельзя
- **Приоритет:** PPM важнее pH для чувствительных растений
- **Стабильность:** Лучше стабильные 90 ppm, чем скачки 60 ↔ 150

### Важные принципы
⚠️ **Фитильный полив** требует более воздухопроницаемого грунта
⚠️ **Застой воды** = гниение корней
⚠️ **Биогумус** — это добавка, а НЕ базовый грунт
⚠️ Всегда используйте **дренажный слой** на дне горшка

## 🔍 Быстрый справочник рисков

**Критичные риски гнили:**
- Бегония макулата - НЕ опрыскивать, НЕ переливать
- Орхидея фаленопсис - НЕ фитиль, полная просушка между поливами

**Чувствительны к переливу:**
- Драцены (обе)
- Хамедорея
- Калатеи (риск гнили при застое)

**Не любят пересыхание:**
- Кротон - следить за балансом

**Устойчивые:**
- Эпипремнум
- Филодендрон
- Монстеры (обе)
- Аглаонема
- Сансевиерия (крайне неприхотлива)
- Хлорофитум

## 🛠️ Варианты смесей

Каждая смесь грунта представлена в **двух вариантах**:
- **Вариант А** - с готовой смесью кокос-перлит (50/50)
- **Вариант Б** - с отдельными компонентами

Выбирайте вариант в зависимости от доступности компонентов.
